# Fresh Facts — setup for Sarah (no coding)

This spreadsheet reads your daily **Index Fresh “Fresh Facts”** email and saves the prices and market notes automatically.

**Use the Google account that receives Giuseppe Bonfiglio’s Fresh Facts email.**

---

## First-time setup (about 5 minutes)

### 1. Make your own copy
Max will send you a link to a template spreadsheet.

1. Open the link  
2. **File → Make a copy**  
3. Name it something like `Summerland Fresh Facts`  
4. Open **your** copy (not the template)

### 2. Connect (one time)
1. Look at the top menu bar for **🥑 Fresh Facts**  
   - If you don’t see it, refresh the page, or wait 10 seconds and refresh again  
2. Click **🥑 Fresh Facts → 1. Connect (one-time setup)**  
3. Click **Yes**  
4. Google will ask for permission — click **Allow** (or Review permissions → Allow)  
   - If Google says “This app isn’t verified,” click **Advanced → Go to … (unsafe)** — this is normal for personal farm scripts Max built for you  
5. If a message says to run Connect again, do that once more after Allowing

### 3. Turn on daily auto-import
1. **🥑 Fresh Facts → 2. Turn on daily auto-import**  
2. Click **OK**

You’re done. Fresh Facts will import around **7:00 AM Pacific** on days Giuseppe sends it.

## Optional (anytime)

| Menu item | When to use |
|-----------|-------------|
| **Import now** | Pull the latest email immediately |
| **Import last 90 days** | Load older Fresh Facts already in your Gmail |
| **Change email sender…** | Only if Import says it found no mail |
| **Show status / help** | See whether Connect / daily import are on |

---

## Where to look

| Tab | What it shows |
|-----|----------------|
| **START HERE** | Status + these instructions |
| **fresh_facts** | One row per day (inventory + commentary) |
| **fresh_facts_prices** | Prices by fruit size |
| **fresh_facts_packed** | Packed inventory by size |
| **fresh_facts_import_log** | “imported / skipped / error” history |

PDF copies are saved in a Drive folder named **Fresh Facts PDFs — …** (link appears on START HERE after Connect).

---

## If something goes wrong

1. Confirm you’re signed into the Gmail that gets Fresh Facts  
2. Open a recent Fresh Facts email and check it still has a PDF attached  
3. Try **Import now** and then open **fresh_facts_import_log**  
4. Screenshot **START HERE** and send it to Max

You should **not** need to open Apps Script or paste any code.
